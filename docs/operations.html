Vận hành kiểm tra API

Một lần mỗi ngày, kiểm tra public market-data endpoints của Binance, OKX, Bybit và KuCoin.

Lịch chạy

GitHub Actions chạy theo cron 17 2 * * * (02:17 UTC hằng ngày), tương đương 09:17 giờ Việt Nam. Có thể chạy thủ công bằng nút “Run workflow”.

Kiểm tra gì?

  • Khởi tạo client CCXT và tải market metadata công khai.
  • Ghi số lượng market, thời điểm kiểm tra và lỗi nếu có.
  • Xuất api-health-report.json thành artifact để xem lại trong 30 ngày.

Giới hạn an toàn

  • Không dùng API key, không gọi endpoint private.
  • Không đặt, sửa hoặc hủy lệnh.
  • Tuân thủ rate limit và timeout.
  • Job báo thất bại nếu bất kỳ sàn nào không kiểm tra được; lỗi có thể do mạng, giới hạn vùng, thay đổi API hoặc lỗi phía sàn, không nhất thiết là downtime toàn hệ thống.

Chạy cục bộ

python -m pip install "ccxt>=4.0.3"
python -m monitoring.api_health

Kiểm tra unit test bằng pytest tests/test_minimal_core.py -q. API health là kiểm thử tích hợp phụ thuộc mạng; không dùng nó thay cho unit test chiến lược.

Các bước tiếp theo

Bổ sung private API checks chỉ khi cần và dùng API key có quyền chỉ đọc. Thêm thông báo Telegram/Email sau khi xác định kênh cảnh báo; không nhúng token vào repo hoặc log.
