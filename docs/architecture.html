DESIGN

Kiến trúc lõi tối giản

Lõi giữ hợp đồng và quy tắc an toàn. Module bên ngoài có thể thay thế độc lập khi tuân thủ contract.

Quy tắc phụ thuộc

  • Core không import module cụ thể. Core chỉ biết các protocol trong minimal_core/contracts.py.
  • Strategy đề xuất, không tự gửi lệnh. Runtime/risk gate chịu trách nhiệm cho phép thực thi.
  • Adapter cô lập khác biệt của từng sàn. Đổi adapter không được làm thay đổi chiến lược.
  • Monitoring độc lập. Kiểm tra API công khai không dùng key và không đặt lệnh.
  • Live trading phải là lựa chọn rõ ràng. Không lấy paper mode làm đường vòng để gửi lệnh thật.
Trạng thái hiện tại: contracts/settings và API health đã được thêm. Runtime giao dịch mới chưa thay thế các entry point cũ; việc chuyển đổi cần test tương thích trước.
