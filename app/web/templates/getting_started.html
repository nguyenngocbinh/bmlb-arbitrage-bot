Quick mental model

ModeBehaviorBeginner
demo_fake_botLive market data + fake money. No exchange keys required.YES
fake-moneyFull bot session with simulated execution and persisted analytics.YES

Recommended path

Demo first, then fake-money, then dry-run with the same command shape you expect to use later.

02

Install

git clone https://github.com/nguyenngocbinhneu/bmlb-arbitrage-bot.git
cd bmlb-arbitrage-bot
pip install -r requirements.txt

For the first run, do not add real exchange credentials.

03

Run the safest demo

Verify dependencies and exchange connectivity without sending orders.

python -m bots.demo_fake_bot --symbol BTC/USDT --exchanges binance okx bybit --duration 5
04

Full paper trading

python main.py fake-money 15 1000 binance kucoin okx BTC/USDT
python -m uvicorn web.app:app --reload --port 8000

Then review sessions, trades, P&L, fees and slippage in Dashboard.

05

Dry-run guard

Use the same command shape as a future live workflow while keeping execution simulated.

python main.py classic 15 1000 binance kucoin okx BTC/USDT --dry-run
python main.py delta-neutral 15 1000 binance kucoin okx BTC/USDT --dry-run
06

Before live trading

  1. Run fake-money sessions for the target exchanges and symbols.
  2. Review dashboard P&L, fees, failed trades and slippage.
  3. Understand API permissions and disable withdrawals on API keys.
  4. Set risk limits and test with the smallest practical trade size.
  5. Expect live results to differ because of latency, liquidity, fees and partial fills.
Risk disclaimer
